# vantage

A command-line tool for managing Lenovo ThinkBook hardware on Windows and
Linux.  It reads and writes performance modes, battery policy, display
settings, BIOS options, firmware inventory and more — without the vendor
control panel, without an account, without telemetry.

Every write is confirmed by an independent readback.  Features the current
machine does not support are reported honestly; nothing is faked.

## Risk notice

Most of this code was generated by AI and verified on a single machine
(ThinkBook 14 G8+, 21VG).  Treat any write command as potentially
destructive.  Always use `--dry-run` first.

## Install

Download `vantage.exe` from
[Releases](https://github.com/cyjin-yl/vantage-cli/releases) and put it
anywhere on your PATH.  No installer needed.  Read commands do not require
administrator privileges; writes may, and require `--yes` to confirm.

On Linux, build from source (see [Building](#building)).

## Usage

```
vantage info                      # model, BIOS, firmware, feature matrix
vantage doctor                    # probe every channel, report problems
vantage capability                # per-command support matrix
```

### Battery and power

```
vantage battery status            # charge level, mode, adapter, telemetry
vantage battery health            # design/full capacity, wear, cycles
vantage battery charge-mode       # current charge policy
vantage battery night-charge on   # enable night charge (--dry-run first)
vantage power scheme list         # Windows power schemes
vantage power ac                  # AC/DC power settings
```

### Performance

```
vantage perf mode                 # current overlay (balanced/quiet/perf)
vantage perf temp                 # CPU/SSD temperatures
vantage perf temp watch           # live temperature stream
vantage perf top                  # process CPU sampling
vantage tune epp <value>          # set Energy Performance Preference
vantage tune profile list         # available tuning profiles
vantage tune profile apply <name> # apply a composite profile
```

### Display

```
vantage panel info                # EDID: resolution, refresh, colour
vantage panel rate <hz>           # set refresh rate (--dry-run first)
vantage panel brightness status   # current brightness
vantage display status            # CCD paths, DPI, HDR, colour store
```

### Input

```
vantage kbd backlight <level>     # off, low, high, auto
vantage kbd fnlock                # Fn lock state
vantage touchpad status           # enabled/disabled
vantage touchpad recover          # unstick a wedged touchpad
```

### Sensors and privacy

```
vantage sense status              # SmartSense/HPD presence detection
vantage sensor list               # all platform sensors with live data
vantage privacy status            # camera, mic, fingerprint state
vantage radio status              # Wi-Fi, Bluetooth, WWAN radios
```

### System

```
vantage security status           # SecureBoot, TPM, BitLocker
vantage storage status            # NVMe health, SMART, temperature
vantage bios list                 # BIOS settings and current values
vantage scan list                 # diagnostic item inventory
vantage update check              # synced update catalog
vantage bluetooth list            # paired devices
vantage wifi status               # WLAN link and security
vantage usb ports                 # hub/port tree with connected devices
```

## Capability matrix

Every command reports its own support status at runtime.  Run
`vantage capability` for the full matrix on your machine.

The reference matrix for ThinkBook 14 G8+ (21VG) is in
[docs/CAPABILITY.md](docs/CAPABILITY.md).  The table includes the
implementation channel (Windows API, Linux sysfs path, etc.) and the
reason for any unsupported entry.

## Architecture

```
vantage (CLI binary)
  └─ vantage-cli        command dispatch, formatting, --json
  └─ vantage-daemon     optional background service (IPC)
  └─ lctrl-core         domain types, validation, no I/O
  └─ lctrl-hal          platform-neutral trait definitions
  └─ lctrl-hal-win      Windows: WMI, IOCTL, RPC, registry, Win32
  └─ lctrl-hal-linux    Linux: sysfs, procfs, ACPI, DRM
  └─ lctrl-tune         profile engine, constraints, telemetry
```

Each hardware channel is a trait in `lctrl-hal`.  The Windows and Linux
backends implement those traits through their respective platform APIs.
The CLI layer has no platform-specific code.

## Design

Unix philosophy, applied to hardware management:

- **One tool, many verbs.**  `vantage` is a single static binary.
  Subcommands map 1:1 to hardware operations.
- **Text by default, JSON with `--json`.**  Human output goes to stdout.
  Structured output for scripts is opt-in.
- **Reads are safe.**  No read command changes hardware state.
- **Writes require confirmation.**  `--yes` to proceed, `--dry-run` to
  preview.  Every write records the previous value, performs the change,
  reads back the result, and reports whether it matches.
- **Honest errors.**  Exit 0 on success, 1 on system error, 2 on usage
  error.  Unsupported features say so; they do not silently succeed.
- **No daemons required.**  The optional daemon provides event
  aggregation and profile automation.  Every command works standalone.
- **No network.**  The tool never phones home.  Update catalog reads
  are from the local registry; remote downloads are transport-gated
  behind the vendor's device credential.

## Building

Requires Rust 1.75+.

```bash
# Linux (native)
cargo build --release
./target/release/vantage info

# Windows cross-compile from Linux
# Needs: rustup target add x86_64-pc-windows-gnu
#        apt install gcc-mingw-w64-x86-64
cargo build --release --target x86_64-pc-windows-gnu

# Windows native
cargo build --release
.\target\release\vantage.exe info
```

## Testing

```bash
cargo test                        # all platforms, unit + contract tests
cargo test -p lctrl-core          # domain model tests
cargo test -p lctrl-hal           # HAL trait contract tests
```

Integration tests that touch real hardware run only on the target machine
and are not part of `cargo test`.
